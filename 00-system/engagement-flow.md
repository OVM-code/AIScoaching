# Master Engagement Flow

The end-to-end project flow for an AI-integration coaching engagement. Two speeds:

- **Full engagement** (large clients like Econocom): 7 phases, ~14–20 weeks to first scaled use cases.
- **AI Kickstart** (SMEs / home services): 5 sessions over ~6 weeks — see `03-clients/sme-home-services/sme-ai-kickstart.md`.

## Flow overview (full engagement)

```
P0 Intake ─► P1 Assessment ─► P2 Strategy ─► P3 Org Redesign ─► P4 Pilots ─► P5 Change & Adoption ─► P6 Scale & Governance
 (wk 0-1)      (wk 1-3)         (wk 3-5)        (wk 5-8)         (wk 8-14)      (parallel wk 5-14)       (wk 14+)
                                                        ▲                            │
                                                        └──── feedback loop ─────────┘
```

Phase 5 (change management) is **not sequential** — it starts the moment strategy direction is set (week 5) and runs in parallel with org redesign and pilots. Communicating late is the #1 failure mode of AI programs.

## Phase gates

Each phase ends with a **gate**: a decision meeting with the sponsor. No gate, no next phase.

| Gate | Decision to be made | Evidence required |
|---|---|---|
| G0 → P1 | "We commit to the assessment" | Signed engagement, sponsor named, intake complete |
| G1 → P2 | "The opportunity is worth a strategy" | Maturity scan + top-10 pain points validated by leadership |
| G2 → P3 | "This is our AI strategy" | Strategy-on-a-page approved, use-case portfolio prioritized, budget envelope agreed |
| G3 → P4 | "This is our target organization" | Target operating model + organigram approved by exec team (and works council informed where required) |
| G4 → P5/P6 | "Pilots proved value — scale or stop per use case" | Pilot scorecards vs. success criteria; scale/iterate/kill decision per pilot |
| G6 | "AI is business-as-usual" | Governance live, benefits tracked quarterly, CoE (or AI owner) operating |

## Cadence & roles

- **Sponsor**: the exec who owns the outcome. Meets you at every gate, unblocks, fronts the change story.
- **Client project lead**: your day-to-day counterpart; co-owns the plan.
- **You (coach)**: facilitate, challenge, generate assets, transfer capability. The goal is that the client can run wave 2 without you.
- Weekly 30-min steering with the project lead; gate meetings with the sponsor; workshops per phase playbook.

## Anti-patterns to watch for

1. **Tool-first thinking** ("we bought Copilot, now what?") → pull back to P1/P2: value first, tools in P4.
2. **Pilot purgatory** — endless POCs, nothing scaled → enforce G4 scale/kill decisions with pre-agreed criteria.
3. **Org chart untouched** — AI bolted onto old structure; benefits evaporate into slack time → P3 is mandatory, not optional.
4. **Change management as a newsletter** → F5: change = sponsor behavior + manager conversations + training + incentives, not comms alone.
5. **Headcount-cut framing leaking early** → workforce messaging rules in F5 §6; leadership aligns on the people story *before* anything is announced.
6. **Shadow AI ignored** — staff already use ChatGPT privately → make it visible in P1, channel it via policy (D29) instead of banning.
