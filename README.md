# AI Integration Coaching System

A complete, reusable system for coaching businesses through AI integration — strategy, organizational redesign, pilots, change management, and scale — designed to be **run entirely with a Claude Pro subscription** (claude.ai Projects, no API needed).

Built for two client archetypes:

1. **Econocom** (and similar large, multi-BU digital services companies) — full 7-phase engagement.
2. **SMEs / KMO's in home services** (HVAC, plumbing, electrical, cleaning, gardening, renovation…) — a compressed 5-session "AI Kickstart" using the same assets.

---

## How the system works

```
Client intake questionnaire ──► client-context.md  (the single source of truth per client)
                                       │
                                       ▼
              Claude Project (one per client, context doc + frameworks uploaded)
                                       │
                                       ▼
        Phase playbooks (02-) ──► copy-paste prompts ──► personalized deliverables
```

Every deliverable in the system is generated by a **numbered prompt** that reads the client's `client-context.md`. You fill in the intake once; every asset after that is personalized automatically.

## The engagement flow (full version)

| Phase | Name | Core question | Key deliverables |
|---|---|---|---|
| 0 | Intake & Discovery | Who is this business and who decides? | Client context doc, stakeholder map, kickoff deck |
| 1 | Assessment | Where are they today? | AI maturity scan, process & pain-point inventory, data readiness report |
| 2 | AI Strategy | Where should AI create value, and in what order? | Strategy-on-a-page, prioritized use-case portfolio, roadmap, business case |
| 3 | Operating Model & Org Redesign | How must the organigram, roles and processes change to capture that value? | Target operating model, redesigned organigram, human+agent process maps, role cards, RACI-A |
| 4 | Pilot Design & Execution | Prove it works in 60–90 days | Pilot charters, agent/automation specs, tool selection, success metrics |
| 5 | Change Management & Adoption | How do people come along? | Change story, ADKAR plan, training curriculum, comms calendar, champions network |
| 6 | Scale & Governance | How does this become permanent? | AI policy, governance charter, CoE design, benefits tracker, EU AI Act compliance check |

SMEs run the compressed version in `03-clients/sme-home-services/sme-ai-kickstart.md` (5 sessions, same prompts, lighter deliverables).

## Quick start

1. Read `00-system/how-to-use-with-claude-pro.md` (10 min).
2. For a new client: copy the intake questionnaire from `00-system/client-intake-questionnaire.md`, run the intake session, and produce `client-context.md` using Prompt 0.1.
3. Create a Claude Project for the client; upload `client-context.md` + the framework files for the current phase.
4. Open the phase playbook and run the prompts in order. Review, edit, deliver.
5. Update `client-context.md` after every phase (each playbook's last prompt does this for you).

## Design principles

- **One context doc per client.** Everything personalizes from it. Keep it current.
- **You are the consultant; Claude is the engine.** Every prompt output is a draft — you validate numbers, names, and feasibility before it reaches the client.
- **Frameworks are opinionated but adjustable.** Scoring weights, phase gates and templates all have stated defaults you can override per client.
- **Human + automation + agent, not "AI replaces people".** The org-design framework (F4) allocates every task to the best executor and redesigns roles around judgment, relationships and exception handling.
- **EU-first compliance.** GDPR and the EU AI Act are built into the governance framework (F6), not bolted on.
